# 📌 Post-it Digital - Guia de Uso

O **Post-it Digital** é um aplicativo web leve e intuitivo para criar, organizar e consultar notas rápidas sem complicações.

---

## 🚀 Como Usar o Aplicativo

### 1. Criar um Novo Post-it
- **Botão Novo Post-it**: Clique no botão **"+ Novo Post-it"** no topo da página (ou no botão flutuante **+** no celular).
- **Digitação Instantânea**: O cursor será focado automaticamente no post-it criado. Basta começar a digitar sua nota.
- **Salvamento Automático**: Você não precisa clicar em "salvar". Todas as alterações são salvas automaticamente no navegador.

### 2. Personalizar Cores
- **Cor Padrão**: No painel superior, escolha uma cor (Amarelo, Azul, Verde, Rosa, Roxo, Laranja ou Cinza) para definir a cor dos novos post-its.
- **Mudar Cor de Nota Existente**: No topo de cada post-it, selecione uma das bolinhas coloridas para alterar a cor daquela nota individualmente.

### 3. Modos de Visualização
Alterne no menu superior entre:
- **Blocos (Mural/Grid)**: Organiza as notas em um painel estilo quadro de avisos.
- **Em Linha (Lado a Lado)**: Organiza as notas horizontalmente em um carrossel deslizável.

### 4. Estilo de Fonte
- Clique no ícone de texto (**T**) na barra superior para alternar entre a **fonte padrão** e a **fonte manuscrita**.

### 5. Buscar e Filtrar Notas
- Digite na barra de pesquisa no topo para encontrar instantaneamente notas por palavra-chave.

### 6. Copiar e Excluir
- **Copiar**: Clique no ícone de cópia no post-it para copiar o conteúdo para a área de transferência.
- **Excluir**: Clique no ícone da lixeira para remover o post-it.
- **Limpar Todos**: Clique em "Limpar todos" no painel de controle para apagar todas as notas de uma vez.

---

## 📲 Como Instalar como Aplicativo (PWA)

O Post-it Digital funciona offline e pode ser instalado na tela inicial do seu dispositivo:
- **No Celular**: Abra o menu do navegador e escolha "Adicionar à Tela Inicial", ou toque no botão **"Instalar App"**.
- **No Computador**: Clique no ícone de instalação na barra de endereço do navegador ou no botão **"Instalar App"**.

---

## 💾 Onde as notas são salvas?
Todas as notas ficam salvas no armazenamento local (**localStorage**) do seu navegador. Seus dados são 100% privados e ficam armazenados apenas no seu próprio dispositivo.
